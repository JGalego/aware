The ledger code in this repo (money, fx, accounts, ledger, report) has several bugs. (1) money.q should round halves away from zero as its docstring says, but 1.245 comes out as 1.24. (2) Rates.rate ignores the date and always returns the newest rate; it must use the most recent rate set on or before the date and raise KeyError if there is none (for the reciprocal direction too). (3) Ledger.post rejects some valid transactions and accepts some invalid ones: the balance check must convert and round each line to the base currency first, then require the sum to be exactly zero. (4) Balances as of a date leave out the transactions dated that very day; as_of is inclusive. (5) trial_balance puts liability, equity and income balances in the wrong column. Find and fix all five.
