Add reservation expiry. reserve(order, item, qty, ttl=None) now stamps the RESERVED event with expires_at = now + ttl, where now is the clock reading used for that event and ttl defaults to the Inventory's default_ttl. A reservation lapses once the clock reaches expires_at (at exactly expires_at it has lapsed), and an order's expiry is the latest expires_at among its reserve events. Lapsed reservations stop counting against availability: Stock.available(item, now=None) and Stock.reserved(item, now=None) ignore lapsed orders as of now (now=None counts everything, as before), and Inventory.available(item) uses the clock. Reserving checks availability as of the clock too, and ship(order) on a lapsed order raises KeyError(order) even if it has not been swept. Add Inventory.sweep(), which emits one RELEASED event (with reason='expired') for each lapsed order, in order-id order, and returns the list of order ids it released; a second sweep right away returns []. Keep each order's expiry in a dict Stock.expiry (order -> expires_at, absent for orders whose events have no expires_at). Snapshots must keep it under the key 'expiry', and rebuilding from a snapshot taken in the middle of the log must give exactly the same state as a full replay. Events written before this change have no expires_at and never lapse.
