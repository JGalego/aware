Add timeouts and cancellation. A Job takes an optional timeout (seconds, default None). run() may now return how long it took (a number, or None meaning 0); if that is greater than the timeout (equal is fine) the attempt counts as a failed attempt with error exactly 'timeout' and the usual retry rules apply. Add Scheduler.cancel(name): a PENDING job becomes CANCELLED (a new constant in job.py, with the value 'cancelled') and so do all its dependents, transitively; cancelling a CANCELLED job does nothing; cancelling a job in any other state raises ValueError('cannot cancel <state> job'); an unknown name raises KeyError. Cancelled jobs never run, even if their dependencies finish. The report summary gets a 'cancelled' count next to the others.
